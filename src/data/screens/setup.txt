Free fetch
 ╭─ {bold}Free fetch{/}
 │ Status  {status}
 │ Gets    most pages: docs, blogs, news, Wikipedia, GitHub, PDFs
 │ Can't   bot walls, JS-only pages, web search, sites that block home IPs
 │         → that's what the paid providers add (their IPs, not yours)
 ╰─
   {bold}Good to know{/}
   Free fetch reads pages from your own internet connection: sites see your home IP.
   Some sites block it or show a bot check; then fats says so and points to a provider.
   Off = every page goes through your paid provider: never your IP, but paid per page.

 │ Status  {status}
 │ What    lets Claude Code, Codex or Cursor use fats by itself
 │ Do      add it once (below), then ask: “read example.com”
 │         runs only while your agent runs · no server, no account

   Claude Code  claude mcp add --scope user fats -- fats mcp
